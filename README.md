# srpgMaker

スマートフォン、特にiPhone Safariからステージを編集してそのままテストプレイできる、見下ろし型ターン制SRPG専用の簡易制作ツールです。アークザラッド風の小規模戦闘を、外部ゲームエンジンなしのCanvas 2Dで試作します。

## ローカルでの起動方法

```bash
npm install
npm run dev
```

表示されたURLを同じネットワーク内のスマートフォンから開くと、実機タッチ操作を確認できます。

## テスト方法

```bash
npm run test
```

Vitestで移動範囲、経路探索、戦闘、勝敗判定、保存データ読込を検証します。

## ビルド方法

```bash
npm run build
```

TypeScriptのstrictチェック後、Viteで静的サイトを`dist/`へ生成します。

## GitHub Pagesの公開方法

`main`ブランチへpushすると、`.github/workflows/pages.yml`が公式Pages Actions方式でビルドし、`dist/`をGitHub Pagesへ公開します。Viteの`base`は`/srpgMaker/`に設定しているため、リポジトリPages配下でもアセットパスが壊れません。

## スマートフォンでの操作方法

- 上部の「編集」で編集モード、「テストプレイ」で編集内容をコピーしたプレイ状態を開始します。
- 下部パレットから「床」「壁」「ジャンプ障害物」「味方」「敵」「消去」を選び、グリッドをタップして配置します。
- 配置は`pointerup`で確定します。指が8px以上動いた場合はスクロール扱いになり、配置しません。
- 「保存」はlocalStorageへ保存し、「読込」はJSONファイルを読み込みます。
- 「JSON出力」は現在の編集データをテキスト欄へ出力します。
- テストプレイでは味方をタップし、青い移動範囲から移動先を選び、「攻撃」または「待機」を選びます。
- 敵ターンでは敵が1体ずつ近い味方へ移動し、隣接できれば攻撃します。

## 現在の制限

- マップサイズは10列×8行固定です。
- ジャンプ障害物は表示のみで、専用のジャンプ移動ルールは未実装です。
- 敵AIは単純な最短距離優先です。
- アニメーションは最小限で、移動は現在瞬間移動に近い表現です。
- JSON読込のバリデーションはプロトタイプ向けの簡易チェックです。
