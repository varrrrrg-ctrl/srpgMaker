# srpgMaker

スマートフォン、特にiPhone Safariからステージを編集してそのままテストプレイできる、見下ろし型ターン制SRPG専用の簡易制作ツールです。アークザラッド風の小規模戦闘を、外部ゲームエンジンなしのCanvas 2Dで試作します。

## ローカルでの起動方法

```bash
npm install
npm run dev
```

表示されたURLを同じネットワーク内のスマートフォンから開くと、実機タッチ操作を確認できます。

## テスト方法

```bash
npm run test
```

Vitestで移動範囲、経路探索、戦闘、勝敗判定、保存データ読込を検証します。

## ビルド方法

```bash
npm run build
```

TypeScriptのstrictチェック後、Viteで静的サイトを`dist/`へ生成します。

## GitHub Pagesの公開方法

`main`ブランチへpushすると、`.github/workflows/pages.yml`が公式Pages Actions方式でビルドし、`dist/`をGitHub Pagesへ公開します。Viteの`base`は`/srpgMaker/`に設定しているため、リポジトリPages配下でもアセットパスが壊れません。

## スマートフォンでの操作方法

- 上部の「編集」で編集モード、「テストプレイ」で編集内容をコピーしたプレイ状態を開始します。
- 下部パレットから「床」「壁」「ジャンプ障害物」「味方」「敵」「消去」を選び、グリッドをタップして配置します。
- 配置は`pointerup`で確定します。指が8px以上動いた場合はスクロール扱いになり、配置しません。
- 「保存」はlocalStorageへ保存し、「読込」はJSONファイルを読み込みます。
- 「JSON出力」は現在の編集データをテキスト欄へ出力します。
- テストプレイを始めると、敵味方を合わせた`speed`降順（同値はユニットID順）で各ユニットが自動選択されます。全生存ユニットが1回ずつ行動すると次のラウンドになります。
- プレイヤーユニットの行動中は、ターン開始位置を基準にした青い移動範囲が表示されます。範囲内の目的地をタップすると最短経路を1マスずつ自動移動し、移動後も範囲内の別地点へ自由に移動できます。
- ジャンプ障害物やユニットは、移動コスト2で向こう側の空いた床へ飛び越えられます。壁は飛び越せず、障害物やユニットの上には停止できません。
- 移動すると進行方向を向きます。操作中のユニット上で20px以上フリックするか方向ボタンを使うと、移動せずに上下左右へ向きを変えられます。
- 「攻撃」は現在向いている正面1マスに敵がいる場合だけ有効になり、ボタンを押すと即座に攻撃して行動を終了します。攻撃せず終える場合は「行動終了」を使います。
- リセット時のテストステージには、Balance (50/20/20)、Attacker (42/26/14)、Tank (70/14/32)、Assault (47/24/18)、Defender (60/18/26) の5味方（HP/ATK/DEF）が配置されます。
- 通常攻撃の基礎ダメージは `0.5 × ATK × √(ATK / DEF)` です。防御側の向きを基準に、正面では1.0倍、側面では1.1倍、背後では1.3倍に補正した後、一度だけ四捨五入します。
- 各味方はタイプ固有のスキルをMPを消費して使用できます。行動中のHP・MP・ATK・DEFとスキル名・消費MPは操作欄で確認できます。
- 各タイプは2つのスキルを持ち、スキル選択後は紫で射程、赤で選択可能な対象、黄で効果範囲が表示されます。敵も同じ射程・範囲・MP・スキル処理を使い、予想ダメージや撃破、複数命中を評価して行動します。
- スキルボタンをタップすると、対象決定前に名前、消費MP、現在MP、射程、範囲、威力、効果説明を確認できます。MP不足のスキルも説明を開くことができ、不足理由が表示されます。
- 編集画面のFactionとUnit TypeからFriendly/Enemyと5タイプを選び、空いている床へ配置できます。配置したタイプはマップ上の短いラベルと保存JSONの`unitType`で確認できます。
- 戦闘・編集の両画面で陣営は青/赤、タイプは独立した丸いB/A/T/S/Dマーカーで表示されます。編集画面で配置済みユニットをタップするとFactionとTypeを確認できます。
- 2ラウンド目以降の開始時に、生存している味方のMPが最大値までの範囲で10回復します。Guardは使用直後から次ラウンド開始まで被ダメージを0.6倍にします。
- 敵も同じ移動・ジャンプ・向き・正面攻撃ルールを使い、自分の行動順で1回だけ自動行動します。

## 現在の制限

- マップサイズは10列×8行固定です。
- 攻撃範囲は現在、向いている方向の隣接1マスです。
- 敵AIは攻撃可能な位置を優先し、攻撃できない場合は最寄りの味方へ近づく簡易方式です。
- アニメーションは最小限で、移動は現在瞬間移動に近い表現です。
- JSON読込のバリデーションはプロトタイプ向けの簡易チェックです。
